## Вариант B

### 1. Скрипт report.sh

Скрипт принимает путь к директории с лог-файлами и уровень сообщений (`ERROR` или `WARN`). Он подсчитывает количество сообщений по модулям и выводит результаты в порядке убывания.

При отсутствии аргументов выводится справка, а программа завершается с кодом `1`.

Дополнительно реализована опция `--top N` для вывода N наиболее активных модулей и проверка существования указанной директории.

### 4. Ответы на контрольные вопросы

**1. Почему пользовательская программа не может напрямую обращаться к диску?**

Пользовательские программы работают в ограниченном режиме доступа. Для взаимодействия с оборудованием и ядром операционной системы они используют системные вызовы. Это обеспечивает безопасность, контроль доступа и защиту данных.

**2. Что дороже: вызов функции или системный вызов? Почему?**

Обычно системный вызов дороже обычного вызова функции, поскольку требует перехода из пользовательского режима в режим ядра и обратно. Обычный вызов функции, как правило, выполняется внутри пользовательского процесса без такого перехода.
